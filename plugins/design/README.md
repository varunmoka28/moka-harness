# design

Design and diagram skills and plugins for interfaces, motion, accessibility and technical figures. Needs nothing; design-direction is macOS only.

## Members

- `design-direction`: Shows design-direction options as rendered mockups in the browser. macOS only (uses open).
- `diagram-design`: Draws diagrams (architecture, flowcharts, sequence, ER and more) as self-contained HTML and SVG. Needs nothing.
- `diagram-pane`: A side pane that pins every diagram Claude draws and keeps a live map of the work. Needs Claude Code 2.1.287 or newer.
- `impeccable`: Design commands for frontend work: critique, audit, polish and anti-pattern checks. Needs nothing.
- `modern-web-guidance`: Keeps Claude current on modern web best practices, including a Chrome extensions skill. Needs nothing.
- `diagram-skills`: Diagram skills: ArchiMate, BPMN, UML, architecture, network, cloud, Graphviz, Vega and others.
- `fireworks-tech-graph`: Draws technical diagrams from a description and exports SVG and PNG.
- `anatomy`: Builds detailed interactive isometric SVG figures that explain a technical idea as a physical object.
- `awwwards`: Builds award-level websites from a one-line prompt: concept, type, motion, checks.
- `frontend-design`: Anthropic's frontend design skill.
- `accessibility`: Web accessibility checks against WCAG 2.2. The plugin loads the author's other web-quality skills too.
- `reanimate`: Clones a section, widget or animation from a reference site or recording into your own code, frame by frame, then checks it.
- `blank-page`: Turns a one-line motion or design brief into a full prompt with references, beats and attached assets.
- `infographics`: Creates infographics with image-generation models and iterative review. Needs the author's API keys.

## What it needs

Needs nothing; design-direction is macOS only.
