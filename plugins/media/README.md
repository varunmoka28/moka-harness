# media

Skills for video and image generation. Some need a paid image or video key.

## Members

- `hyperframes`: HeyGen's HyperFrames: write HTML, render video. The plugin loads the author's whole skill set.
- `gpt-image-2`: Image generation and editing skill for GPT Image 2, with prompt templates. Text is mostly in Chinese.
- `make-ugc`: treg's make-ugc workflow: short user-style videos. Needs a treg account.

## What it needs

Some need a paid image or video key.
