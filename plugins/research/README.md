# research

Paper search, science, web and video research skills plus a subreddit watcher. Needs a free alphaXiv account for the paper search server, and ffmpeg and yt-dlp for watch.

## Members

- `reddit-watch`: Watches subreddits you choose, has Claude's small model (Haiku) pick out posts that could improve your Claude Code use, and lists them with links in a side pane. Off until you turn it on. Contacts reddit.com and sends post text to Haiku once you run /reddit on; off until then.
- `watch`: Lets Claude watch a video from a link or file: frames, captions or Whisper transcript. Needs ffmpeg and yt-dlp.
- `k-dense-science`: K-Dense scientific skills: literature review, scientific writing, data access, plotting and peer review.
- `orchestra-research`: Orchestra Research's autoresearch skill: runs autonomous research projects as an inner experiment loop and an outer steering loop.
- `book-to-skill`: Converts a book or document into a structured agent skill.
- `anysearch`: Specialist search for finance, legal, code, security, academic and other domain queries, for when native web search is not enough.
- `agent-reach`: Lets an agent search or read the web, Twitter/X, Reddit, YouTube, GitHub and more.
- `graphify`: Turns code, documents, papers and images into a knowledge graph with an HTML report.
- `big-arrow`: Points at a spot on the user's macOS screen with the bigarrow command-line tool.
- `supabase-skills`: Supabase's skills for Supabase and Postgres best practice.

## What it needs

Needs a free alphaXiv account for the paper search server, and ffmpeg and yt-dlp for watch.

## MCP servers

- `alphaxiv`: alphaXiv paper search over HTTP. Needs the token you set when you enable the plugin.

Secrets are asked for when you enable the plugin and are never written to this repository.
