# band-frame

A frame around the band above the prompt.

## What it does

Draws a heavy rule at the top of the above-prompt band in the theme's blue accent colour and tints its background `#3a342b`. Both are fixed in the source.

## What it needs

Claude Code with plugin mods support. Nothing else.

## Hook events it uses

`ui.render` on the above-prompt band.

## What it deletes or stops

Nothing.

## What it sends off the machine

Nothing.
