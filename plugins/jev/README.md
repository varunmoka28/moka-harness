# jev

Mods and skills built on the TypeSafe (Jev) models. Needs a TypeSafe API key, paid per call.

## Members

- `prompt-enhancer`: Rewrite a rough prompt in place using project rules and Jev-ranked skills. Needs a TypeSafe API key; calls are paid.
- `run-ledger`: Estimated API cost per run, model and plugin, subagent status, and optional Jev model advice. Jev advice needs a TypeSafe API key; calls are paid.
- `typesafe`: Skills for designing workflows with the TypeSafe System One API and finding its current docs. Needs nothing to install.

## What it needs

Needs a TypeSafe API key, paid per call.
