# band-frame

A frame around the band above the prompt.

## What it does

Draws a rule at the top of the above-prompt band and tints its background. The two colours, `#3a342b` and `#c9a96e`, are fixed in the source.

## What it needs

Claude Code with plugin mods support. Nothing else.

## Hook events it uses

`ui.render` on the above-prompt band.

## What it deletes or stops

Nothing.

## What it sends off the machine

Nothing.
